## Task 01: Create an agent

> [!WARNING]
> Copilot Studio is evolving rapidly, so your experience might differ from these instructions.
> During testing, Copilot Studio suggested knowledge sources, tools, and triggers for the agent.
> Remove all the suggestions.

1. In the web browser, go to `https://copilotstudio.microsoft.com/`.

1. In the bottom-left corner of the page, select the ellipsis **(...)** next to your username and select **Open classic experience**.

1. In the **Share feedback before opening the previous experience?** dialog, select **Skip feedback**. The classic experience opens in a new browser tab.

1. If the **Welcome to Microsoft Copilot Studio** dialog appears, select **Get Started** and skip any additional welcome messages.

1. At the top right of the page, select your demo environment.

    ![Demo environment selector](../../media/2xg8et8h.jpg)

1. In the left navigation pane, select **Agents**.

    ![Agents option in the left navigation pane](../../media/53scvlzj.jpg)

1. In the **Start building by describing what your agent needs to do** text field, enter the following information:

	```
    Create an agent named Coffee Machine Support Assistant that will be used to answer customers questions related to troubleshooting, billing, and order issues as it relates to coffee machines.
    ```

    ![Description entered in the agent creation field](../../media/7096jy8m.jpg)

   > [!NOTE]
   > It may take a couple of minutes for the agent to be provisioned. 

1. Scroll to the **Knowledge** section.

    ![Knowledge section](../../media/qcw75pdk.jpg)

1. For each suggested knowledge source, select **Dismiss**.

    ![Dismiss option for a suggested knowledge source](../../media/8scl1z93.jpg)

1. Select **+ Add knowledge**.

1. In the **Upload file** area, select **select to browse**.

    ![Select to browse option in the Upload file area](../../media/4kqyk1f7.jpg)

1. Go to the location where you saved all of the files that you downloaded from GitHub in the prerequisite lab. In the **Customer Intent Lab** folder, select **Coffee Machine Support Knowledge Base.docx** and then select **Open**.

   > [!NOTE]
   > You can download the files from:
   > `https://github.com/skillable-custom-lab-development/40-505-52/blob/main/Dynamics%20365%20Labs.zip`.

    ![Coffee Machine Support Knowledge Base file selection](../../media/xar9vm3x.jpg)

1. Select **Add to Agent**.

    ![Add to Agent option](../../media/0ygcm6cp.jpg)
    ![Knowledge source added to the agent](../../media/4h3417z0.jpg)

1. Dismiss any suggestions in the **Tools** section if they appear.

1. Dismiss any suggestions in the **Triggers** section if they appear.

    ![Tools and Triggers sections](../../media/x53ezup6.jpg)

1. Leave the agent page open for the additional configuration steps in the next task.
