## Task 03: Configure capacity

When you demonstrate the functionality, the agent might not route conversations to you as expected. This is generally because AI agents are assigned more capacity when they are created than your demo account probably has.

To prevent this issue, ensure that your admin/demo account has more capacity assigned to it.

1. Open the **Copilot Service admin center** app.

	![Copilot Service admin center app](../../media/64fsled9.jpg)

1. In the left navigation pane, in the **Customer support** section, select **User Management**.

	![User Management option in Customer support section](../../media/3c31r8ne.jpg)

1. On the **User Management** page, locate **Users** and then select **Manage**.

	![Manage users](../../media/f1w55pwl.jpg)

1. Search for and select the administrative account for your demo environment.

	![Select administrative account for demo environment](../../media/940tvgqh.jpg)

1. On the command bar, select **Omnichannel**.

	![Omnichannel option on command bar](../../media/vpyqmfs3.jpg)

1. In the **User Details** tile, in the **Capacity** field, enter `2,147,483,647`.

	![Capacity field for admin/demo account](../../media/yvx9tx1n.jpg)

1. On the command bar, select **Save and Close**.

	![Save and Close](../../media/qw5nhz01.jpg)

   > [!WARNING]
   > Changes to the Omnichannel configuration can take 15 minutes to propagate through the system and become effective.

1. At the top left of the page, select **Enabled Users** and change the value to **Agents**.

	![Enabled Users set to Agents](../../media/t89z5vxm.jpg)

   > [!NOTE]
   > If you do not see the agent listed, select **AI Agents**, under **Customer support** in the left navigation pane.
	
1. In the list of agents, select **Copilot Coffee Machine Support Assistant**.

	![Select Copilot Coffee Machine Support Assistant](../../media/ryf61y62.jpg)

	> [!NOTE]
    > In the current **Copilot Service admin center** experience, selecting the agent may open it in **Copilot Studio**. The **Omnichannel** tab and **Capacity** field shown in earlier versions may no longer be available from the agent record. If these options are unavailable, skip the capacity configuration and continue to the next task.

1. On the command bar, select **Omnichannel**.

	![Omnichannel tab](../../media/3ce94ysa.jpg)

1. In the **User Details** tile, in the **Capacity** field, enter `500,000`.

	![Capacity field](../../media/v2oih6j6.jpg)

1. On the command bar, select **Save and Close**.
