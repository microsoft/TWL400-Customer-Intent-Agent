## Task 01: Enable intent-based suggestions for service representatives

> [!NOTE]
> If you are using a trial experience profile, all the necessary Copilot features, including Intent Suggestions, are already enabled. You cannot edit the default profiles. Proceed to the next task.


In this task, you'll add the Copilot features to an experience profile.

1. Open the **Copilot Service admin center** app.

	![Copilot Service admin center app](../../media/64fsled9.jpg)

1. In the left navigation pane, in the **Support experience** section, select **Workspaces**. 

	![Workspaces option in Support experience section](../../media/2gsq01ca.jpg)

1. Locate **Experience profiles** and then select **Manage**.

	![Manage experience profiles](../../media/3x87w4jc.jpg)

1. In the list of experience profiles, select **Customer Service Trial profile**.

	![Select Customer Service Trial profile](../../media/5dzftrtm.jpg)

1. On the **Productivity pane** trial, select **Edit**.

	![Edit Productivity pane trial](../../media/tbbcbcqv.jpg)

1. On the **Copilot help pane** tile, set **Copilot help pane** to **On**.

	![Turn on Copilot help pane](../../media/9s902spq.jpg)

1. On the **Customer Service Trial profile** page, on the **Copilot AI features** tile, select **Edit**.

1. Select the following options:

    - **Ask a question**.
    - **Intent-based suggestions (preview)**.

	![Enable Copilot AI features](../../media/vi43plfe.jpg)

1. Select **Save and Close**.
