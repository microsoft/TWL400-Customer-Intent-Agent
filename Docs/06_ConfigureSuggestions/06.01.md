## Task 01: Create an agent

In this exercise, you're going to create a different agent. You'll create a new agent that can answer using general web knowledge, and you'll also connect it to Dynamics 365 so it can surface intent-based suggestions to guide the conversation.

1. In your web browser, go to `https://copilotstudio.microsoft.com/`.

1. In the bottom-left corner of the page, select the ellipsis **(...)** next to your username and select **Open classic experience**.

1. In the **Share feedback before opening the previous experience?** dialog, select **Skip feedback**. The classic experience opens in a new browser tab.

1. Select your demo environment.

    ![go to classic experience](../../media/gw15orym.jpg)

1. In the left pane, select **Agents**.

1. On the **Agents** page, enter the following description in the prompt box at the top of the page:

	``` Text
    Create an agent named Intent Coffee Support Assistant that will be used to answer customers questions related to troubleshooting, billing, and order issues as it relates to coffee machines.
    ```

1. Select **Send**.

   > [!WARNING]
   > Wait for the agent to be created.In this agent. This may take several minutes. You're not going to add any knowledge directly to the agent. The agent will use general knowledge from the internet and will also use the intents you created. 

1. On the command bar for the **Intent Coffee Support Assistant** agent, select **Settings**.

    ![Intent Coffee Support Assistant Settings](../../media/custintent_037.png)

1. On the **Security** page, in the **Authentication** section, select **No Authentication**.

    ![Intent Coffee Support Assistant No Authentication](../../media/ke0nniet.jpg)

1. Select **Save**. 

1. In the confirmation dialog, select **Save**.

1. Close the **Settings** page.

1. On the command bar for the agent, select **Publish**.

1. In the confirmation dialog, select **Publish**.

1. Wait for the agent to be published.

1. Select **Channels**.

1. Select **Dynamics 365 Contact Center**.

1. In the **Dynamics 365 Contact Center** pane, select **Connect**.

1. Wait for the connection to be established.
