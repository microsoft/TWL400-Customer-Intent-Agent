## Task 02: Set up Copilot agents for intent management

1. Open the **Copilot Service admin center** app.

	![Copilot Service admin center](../../media/64fsled9.jpg)

1. In the left navigation pane, in the **Customer support** section, select **Intent**. 

	![Intent-based suggestions section](../../media/8m44j1g3.jpg)

1. In the **Intent-based suggestions** section, locate **Enable for chatbots** and then select **Manage**. 

	![Manage intent for chatbots](../../media/2pe1ri5u.jpg)

1. Select the **Intent Coffee Support Assistant** you created earlier. Then, on the command bar, select **Manage type**.

	![Select Intent Coffee Support Assistant](../../media/lm5dxv1k.jpg)

1. Select **Uses AI-generated intents**.

	![Uses AI-generated intents](../../media/a1gfjczw.jpg)

1. Select **Digital only** and then select **Save**.

> [!NOTE]
> In some environments, selecting Uses AI-generated intents may show the error **Failed to retrieve ResolveConnection**. This preview feature depends on tenant-level configuration that might not be available in the lab environment. If you see this error, select **Cancel** and continue with the next task.
